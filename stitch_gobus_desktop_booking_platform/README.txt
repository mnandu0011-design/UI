# GoBus Fixed Website

## How to open
1. Extract this ZIP file.
2. Open the `stitch_gobus_desktop_booking_platform` folder.
3. Double-click `index.html`.
4. The Home page will open.
5. Navigation links now point to the correct `code.html` files.

## Main pages
- Home: `gobus_home_1/code.html`
- Search Buses: `gobus_search_buses/code.html`
- My Bookings: `gobus_my_bookings/code.html`
- Help: `gobus_help_support_desk/code.html`
- User Profile: `gobus_user_profile_preferences/code.html`
- Settings: `gobus_settings_preferences/code.html`
- Live Tracking: `gobus_route_itinerary_live_tracking/code.html`

The existing design and page content were preserved; the main file-navigation links were corrected.
