# 🚀 Modern SaaS UI Collection

A collection of modern, responsive SaaS user-interface templates built with **HTML, CSS, and JavaScript**.

The project provides several reusable UI examples for common SaaS applications, including landing pages, dashboards, pricing pages, and team-management interfaces.

## ✨ Features

* 🎨 Modern and clean UI design
* 📱 Responsive layout for desktop and mobile
* 🏠 SaaS landing page
* 📊 Interactive SaaS dashboard
* 💰 Pricing page with multiple plans
* 👥 Team management interface
* ⚡ Lightweight HTML, CSS, and JavaScript
* 🔗 Easy navigation between UI templates

## 🖥️ UI Templates

### 🏠 SaaS Landing Page

A modern landing page containing:

* Hero section
* Feature sections
* Call-to-action buttons
* Responsive design

### 📊 SaaS Dashboard

A dashboard interface featuring:

* KPI cards
* Revenue analytics
* Charts
* Recent activity

### 💰 SaaS Pricing

A pricing interface containing:

* Free plan
* Pro plan
* Business plan
* Monthly/yearly billing options

### 👥 Team Management

A team-management interface that includes:

* Team member search
* Member roles
* Team member management
* Invite functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mnandu0011-design/UI.git
```

### 2. Open the project

Navigate into the project:

```bash
cd UI
```

### 3. Run the project

This project does not require a backend or build process.

You can open:

```text
index.html
```

directly in your browser.

You can also use a local development server such as VS Code Live Server.
