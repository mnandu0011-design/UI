# rapido
# Rapido Ride Booking Website 🏍️

A simple ride-booking website created using HTML, CSS, and JavaScript.

## Live Demo

[Rapido Ride Booking](https://venkatalikith-1705.github.io/rapido/)

## Technologies Used

* HTML
* CSS
* JavaScript
* Leaflet.js
* OpenStreetMap

## Features

* Bike, Auto, and Cab selection
* Pickup and destination search
* Interactive map
* Estimated fare calculation
* Simulated rider tracking
* Ride receipt download

## How to Run

Open `index.html` in your browser or use VS Code Live Server.

## Note

This is a demo project created for educational purposes. It does not provide real rides or payments.
